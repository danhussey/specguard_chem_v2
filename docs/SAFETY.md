# Safety

This project ranks provided public candidate IDs. It does not generate novel
molecules, propose synthesis routes, or recommend clinical or therapeutic use.

Outputs are retrospective computational prioritisation results only. A selected
compound must not be described as safe, effective, selective, synthesizable, or
therapeutically useful unless that evidence is explicitly present in the source
data and the claim is scoped as retrospective evidence.

The first version avoids open-ended molecular generation to keep the evaluation
grounded in public measured activity data.
